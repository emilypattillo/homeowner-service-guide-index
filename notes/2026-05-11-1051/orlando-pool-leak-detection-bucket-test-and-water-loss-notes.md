# Orlando pool leak detection: bucket-test and water-loss notes

A simple bucket test is often the least disruptive first step before a homeowner assumes every drop in water level is a shell or plumbing leak. Wind, splash-out, autofill behavior, and recent backwashing can all make the pool look suspicious for a day or two, so notes should include weather, pump run time, and whether the level falls faster with the equipment on.

For Orlando-area homeowners who want a plain pre-call checklist, this reference is useful to compare normal evaporation clues against leak-warning patterns: https://poolleakdetectionorlando.com/
